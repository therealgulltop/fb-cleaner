# fb-cleaner

Two userscripts, desktop and mobile, that hide Facebook ads, suggested posts and Reels.  They read the page the way you see it, so Facebook's scrambled "Sponsored" labels don't fool them.

| Script | For | What it does |
|---|---|---|
| [FB Cleaner (Desktop)](https://raw.githubusercontent.com/therealgulltop/fb-cleaner/main/fb-cleaner-desktop.user.js) | Desktop facebook.com | Hides ads and Follow/Join suggestions using Facebook's own hide button, and shows the advertiser's name in place of Facebook's message.  Undo is respected. |
| [FB Cleaner (Mobile)](https://raw.githubusercontent.com/therealgulltop/fb-cleaner/main/fb-cleaner-mobile.user.js) | Facebook's mobile layout (e.g. Quetta on Android) | Collapses ads, Follow/Join suggestions, "Suggested for you" blocks and the Reels tray on screen only.  Tap the gear for settings. |

## Install

1. Install the [Tampermonkey](https://www.tampermonkey.net/) extension.
2. In Chrome or Edge, open the extension's details page and turn on **Allow User Scripts**.
3. Click a script link above, then **Install**.

Tampermonkey checks this repo for updates automatically.
